# @imvu/xmlrpc

## 0.1.0

### Minor Changes

- 3ea9357: New `@imvu/xmlrpc` package: a dependency-free, browser-capable client for IMVU's legacy XML-RPC gateway. Includes the wire codec, request signing (`X-imvu-auth`), login (`test.avatarInfoForLogin2`), and `authorizeProducts()`, which resolves products to their current CFL URL, checksum and parent product.
