# @imvu/cal3d

## 0.1.0

### Minor Changes

- 8f2c076: New `@imvu/cal3d` package: a dependency-free, browser-capable reader and writer for the Cal3D files IMVU products use — skeletons (`.xsf`/`.csf`), meshes (`.xmf`/`.cmf`), materials (`.xrf`/`.crf`), animations (`.xaf`/`.caf`, including IMVU's compressed keyframes) and morph animations (`.xpf`/`.cpf`) — in both the binary and XML flavors, as an object model (`Skeleton`/`Bone`, `Mesh`/`Submesh`/`Vertex`/`MorphTarget`, `Material`/`TextureMap`, `Animation`/`Track`/`Keyframe`, `MorphAnimation`/`MorphTrack`).
